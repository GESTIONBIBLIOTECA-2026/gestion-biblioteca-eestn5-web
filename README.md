# 📚 Sistema de Gestión de Biblioteca — WEB

Este repositorio corresponde al **desarrollo de la versión web del Sistema de Gestión de Biblioteca**, realizado como parte del proyecto escolar de la EEST N.º 5.

## 📌 Organización de los repositorios

A partir de ahora, vamos a diferenciar los repositorios según la plataforma que estemos desarrollando:

- **WEB:** este repositorio estará destinado exclusivamente al desarrollo de la página web del sistema de gestión de biblioteca.
- **APLICACIÓN MÓVIL:** el repositorio anterior seguirá correspondiendo al desarrollo de la aplicación móvil.

Esta separación tiene como objetivo mantener una mejor organización del proyecto, facilitar el trabajo de cada integrante y evitar confusiones entre el código y los avances de ambas plataformas.

## 👥 Organización de los grupos

El desarrollo se encuentra dividido en tres grupos de trabajo, cada uno con responsabilidades específicas dentro del sistema.

### Grupo 4 — Gestión de pedidos y coordinación

Responsabilidades principales:

- Creación y registro de pedidos.
- Validación de disponibilidad de libros y estado de los usuarios.
- Control del estado de los pedidos.
- Consulta del historial de pedidos.

### Grupo 5 — Gestión de usuarios

Responsabilidades principales:

- Alta, modificación y baja de usuarios.
- Búsqueda avanzada por nombre, DNI y curso.
- Gestión de los datos personales de los usuarios.
- Registro de entregas, devoluciones y atrasos.
- Panel de administración.

### Grupo 6 — Gestión de inventario y catálogo

Responsabilidades principales:

- Registro, modificación y baja de libros.
- Búsqueda de libros mediante filtros por categoría, título, autor y disponibilidad.
- Actualización del stock.
- Control del estado de los libros: disponible o prestado.

## 📖 Documentación y metodología de trabajo

Para mantener una forma de trabajo organizada y coherente entre ambos repositorios, **cualquier duda relacionada con el desarrollo, la organización, los criterios de implementación o la documentación del proyecto se trabajará siguiendo la misma metodología utilizada en el repositorio de la aplicación móvil**.

Repositorio de referencia:

🔗 [Gestión de Biblioteca — Aplicación Móvil | Documentación](https://github.com/GESTIONBIBLIOTECA-2026/gestion-biblioteca-eestn5-app/tree/main/docs)

Ante cualquier duda, se deberá consultar la documentación existente y mantener los criterios de trabajo establecidos para el proyecto. Si surge una situación que no esté contemplada, se deberá conversar con el equipo antes de implementar una solución que pueda afectar al resto del sistema.

## 🌿 Organización del trabajo con Git

El repositorio utilizará una estructura de ramas para organizar el desarrollo, separar las tareas de cada integrante y controlar la incorporación de cambios.

La integración del código se realizará mediante **Pull Requests**, para que los cambios puedan revisarse antes de incorporarse a las ramas principales.

Las reglas de colaboración, los nombres de las ramas y los permisos se establecerán en la configuración del repositorio.

## 🎯 Objetivo del repositorio

Desarrollar la versión web del Sistema de Gestión de Biblioteca de manera organizada, colaborativa y coherente con los criterios definidos para el proyecto, manteniendo una separación clara respecto de la aplicación móvil y facilitando la integración del trabajo realizado por los distintos grupos.
